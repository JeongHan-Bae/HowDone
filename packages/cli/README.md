# HowDone CLI

HowDone CLI reads a local Markdown file and reports hierarchical task-list
progress.

```bash
npm install --global howdone-cli
howdone tasks.md
```

The `howdone-cli` package installs the `howdone` command and depends on the
dependency-free `howdone` hexagonal core package. The complete command syntax
is documented in [`docs/syntax.md`](docs/syntax.md).
